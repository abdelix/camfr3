# About

## History

CAMFR was written by Peter Bienstman at the Photonics Research Group of Ghent
University (INTEC), from 1998, with contributions from Lieven Vanholme, Mihai
Ibanescu and others (see
[AUTHORS](https://github.com/abdelix/camfr3/blob/main/AUTHORS)). It was
distributed from [SourceForge](http://camfr.sourceforge.net/) for Python 2 and
later maintained on GitHub by
[Demis D. John](https://github.com/demisjohn/CAMFR).

camfr3 ports it to Python 3 and modernises the build: CMake and
scikit-build-core instead of SCons, pybind11 instead of Boost.Python, a pytest
testsuite with sanitizer runs in CI, and binary wheels. Every change is
recorded in
[PORTING_JOURNAL.md](https://github.com/abdelix/camfr3/blob/main/PORTING_JOURNAL.md).
camfr3 is maintained by Abdelfettah Hadij-ElHouati
([@abdelix](https://github.com/abdelix)) as a side project.
